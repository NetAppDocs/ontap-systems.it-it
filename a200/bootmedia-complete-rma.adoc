= Restituisci il supporto di avvio AFF A200 guasto a NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Restituisci il supporto di avvio AFF A200 guasto a NetApp dopo aver sostituito il supporto di avvio, come descritto nelle istruzioni RMA fornite con il kit. Vedi la pagina  https://mysupport.netapp.com/site/info/rma["Restituzione e sostituzione delle parti"] per ulteriori informazioni.
