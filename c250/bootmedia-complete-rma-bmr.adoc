= Restituisci il supporto di avvio AFF C250 guasto a NetApp dopo il processo di ripristino automatico dell'avvio
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo che hai sostituito il supporto di avvio in un sistema AFF C250, restituisci il componente guasto a NetApp, come descritto nelle istruzioni RMA fornite con il kit. Vedi la pagina  https://mysupport.netapp.com/site/info/rma["Restituzione e sostituzione delle parti"] per ulteriori informazioni.
