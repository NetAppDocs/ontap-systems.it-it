= Sostituisci a freddo uno shelf DS212C, DS224C o DS460C
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Devi eseguire una sostituzione a freddo dello shelf quando sostituisci uno shelf di dischi in un sistema di produzione con dischi in uso. Questa è una procedura invasiva che richiede di arrestare i controller della tua coppia HA.

Questa procedura si applica agli shelf con moduli IOM12, IOM12B o IOM12C.

Consultare l'articolo della Knowledge base di NetApp https://kb.netapp.com/onprem/ontap/hardware/How_to_replace_a_shelf_chassis_using_a_cold_shelf_removal_procedure["Come sostituire il telaio di un ripiano utilizzando una procedura di rimozione del ripiano a freddo"].
