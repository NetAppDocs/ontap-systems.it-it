= Restituisci il supporto di avvio FAS2700 guasto a NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo aver sostituito il supporto di avvio sul sistema FAS2700, restituisci il componente difettoso a NetApp, come descritto nelle istruzioni RMA fornite con il kit.

Vedi la pagina  https://mysupport.netapp.com/site/info/rma["Restituzione e sostituzione delle parti"] per ulteriori informazioni. Il sistema FAS2700 supporta solo procedure manuali di ripristino del supporto di avvio. Il ripristino automatico del supporto di avvio non è supportato.
