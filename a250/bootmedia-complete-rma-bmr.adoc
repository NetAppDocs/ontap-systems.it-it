= Restituisci il supporto di avvio AFF A250 guasto a NetApp dopo il processo di ripristino automatico dell'avvio
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se un componente nel tuo sistema AFF A250 si guasta, restituisci la parte guasta a NetApp. Consulta la  https://mysupport.netapp.com/site/info/rma["Restituzione e sostituzione delle parti"] pagina per ulteriori informazioni.
