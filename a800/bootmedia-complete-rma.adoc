= Restituisci il supporto di avvio AFF A800 guasto a NetApp dopo il processo di ripristino manuale dell'avvio
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo aver completato la procedura di ripristino manuale dell'avvio per un supporto di avvio non funzionante nel tuo sistema AFF A800, restituisci la parte guasta a NetApp. Vedi la pagina  https://mysupport.netapp.com/site/info/rma["Restituzione e sostituzione delle parti"] per i dettagli.
